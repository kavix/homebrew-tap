# Homebrew Tap for OpenShomer

Homebrew Tap for installing **OpenShomer** — Autonomous AI Agent Security Engineer.

## Installation

```bash
brew tap kavix/tap
brew install openshomer
```

## Quick Start

```bash
# Launch interactive Textual TUI
openshomer tui

# Scan any agent repository
openshomer scan /path/to/agent-repo

# Automatically remediate and open PR on GitHub
openshomer auto-pr /path/to/agent-repo --repo owner/agent-repo
```
